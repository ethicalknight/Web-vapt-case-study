## DVWA
Practiced SQL injection (including blind), reflected and stored XSS, CSRF, command injection, file upload, and brute force across Low, Medium, High, and Impossible.
Key learning: at Low nothing is defended, Medium has weak filters that can be bypassed, High is stronger but still flawed, and the Impossible source shows the real fix (prepared statements, anti-CSRF tokens).
